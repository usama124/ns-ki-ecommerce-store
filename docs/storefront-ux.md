# Product-first storefront layout

Shop by Video has always-visible previous/next controls, an overflow hint, a visible-reel range and a subtle edge fade when more reels remain. The scrollbar beneath the reels is hidden; arrows, touch scrolling and keyboard scrolling remain available. Buttons disable at the ends; keyboard users can focus the reel track and use Left/Right. Existing quick-shop/video controls remain intact. Scroll updates use the actual rendered card dimensions, and resize observation keeps the range accurate. Reduced-motion preferences disable smooth scrolling.

Homepage featured/video sections use tighter heading and section spacing, with less trailing padding before the footer. Reels align with featured product-card columns (two on mobile, three on tablet, four on desktop), use the product images' 3:4 frame, and no longer impose oversized minimum widths. Quick-shop content stacks on narrow screens to fit the smaller cards. An isolated Chromium regression test checks actual product/reel widths, alignment, proportions and quick-shop interaction at 375, 640, 768, 1024 and 1440 pixels.

The homepage retains its existing banner. All storefront pages, including the homepage, use the same compact logo/header row, announcement bar and tighter navigation spacing, while keeping announcement text, search, member/cart controls and category navigation. Shop/category pages remove stacked top margins, decorative collection banners and repeated category pills. A compact heading retains the category title and result count; descriptions remain accessible under an About this collection disclosure.

On mobile, search and Filters & sort share a row. Category/subcategory/sort controls are collapsed initially, with an explicit Show products action and automatic dismissal when a category/sort link is chosen. The desktop sidebar stays visible and scrollable. Existing filtering, sorting and pagination queries are unchanged. Submitting a new search resets stale pagination.

Product pages have a lighter breadcrumb row, tighter gallery/detail spacing, a smaller mobile gallery (still 2:3, with zoom available), smaller thumbnails and a more compact title/price panel. On mobile, product details and purchase controls now follow the gallery directly, before the full inline video; the floating preview is retained. Desktop keeps the existing two-column gallery/video and detail layout. The redundant category heading above the product title is removed; category links remain in the breadcrumb and product tags. Sale headers and account/content page top spacing are also reduced. These changes preserve the dark teal palette, typography and purchasing controls.

Vitest covers reel range/end states, arrow and keyboard scrolling, resize/reduced-motion behavior, nested card controls, mobile filter expansion and accessible compact headings. The isolated Chromium fixture renders the real carousel/collection components and theme CSS at mobile and desktop widths, with a placeholder navigation bar and sample cards (no database/R2 access). It verifies product placement, filter visibility and real scroll behavior; it is not a screenshot test of live store data. Use staging to check long real category names and product titles, the complete header, and iOS touch scrolling before release.
